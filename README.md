# Zefiro AR

Realtà aumentata in campo (Meta Quest 3, WebXR + three.js) per vedere in scala reale
gli aerogeneratori di progetto dal punto di vista. Dati: `Sopralluogo_dati.json`
esportato dal plugin QGIS **Zefiro** (famiglia Poliedra).

Pagina: https://diegodebenedittis.github.io/zefiro-ar/

Registrazione senza GPS/bussola: punto noto + allineamento della skyline del DTM
alle creste reali, verifica su riferimenti noti.

Non caricare qui i JSON dei progetti: il repo è pubblico.
