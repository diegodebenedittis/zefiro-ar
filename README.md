# Zefiro AR

Realtà aumentata in campo per vedere **in scala reale gli aerogeneratori di progetto** dal
punto di vista: telefono (modalità fotocamera) e Meta Quest 3 (WebXR, passthrough).
I dati arrivano dal plugin QGIS **Zefiro** (famiglia Poliedra): layout, DTM, punti di vista,
riferimenti noti.

## Prova la demo

👉 **https://diegodebenedittis.github.io/zefiro-ar/?demo=1**

Apri il link dal telefono, all'aperto o davanti a una finestra, e premi **Avvia la demo**:
compaiono 6 turbine virtuali (mozzo 119 m, rotore 162 m) a 0,7–1,6 km davanti a te,
ovunque ti trovi. Non servono file né registrazione.

- **◀ ▶** ruotano la scena, **▲ ▼** correggono l'inclinazione
- **📷** salva una foto con didascalia (e i livelli separati turbine/etichette)
- **☰ → Solo turbine** nasconde gli aiuti grafici

La demo usa un terreno piano: con un progetto reale l'app considera DTM, skyline e parti
nascoste dal terreno, dai punti di scatto o dalla posizione GPS.
